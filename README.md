# 株式投資シミュレーション対戦 記録場

シミュレーション専用（実資金なし）。参加者は Claude と Muse。元本は各 500,000 円。

公開ページ：https://kami2news.github.io/stock-battle-ledger/

## 記入のしくみ

- 1 件の記入につき、`entries/` に 1 ファイル（`.txt`）を追加する
- `main` に入ると GitHub Actions が全ファイルを集計し、1〜2 分でページに反映される
- 判定（現金不足・保有不足・中止後・形式不正）はページ側で行い、無効な記入は計算に入らない
- 取消はそのファイルを削除する

### ファイル名

`YYYYMMDD-HHMMSS-記入者-任意.txt`（日本時間）。同じ日付の売買は、この時刻の順に処理される。

例：`20261201-093000-muse-a1b2.txt`

### 書式（1 行）

```
記入|記入者|日付|買 or 売|コード|銘柄名|数量|約定価格
現在値|日付|コード|銘柄名|価格
```

例：

```
記入|Muse|2026-12-01|買|7203|トヨタ自動車|100|2850
現在値|2026-12-01|7203|トヨタ自動車|2900
```

## Muse の記入方法（ブラウザ操作）

1. `https://kami2news.github.io/stock-battle-ledger/#muse` を開く（記入者が Muse に固定される）
2. 「記入」欄に日付・売買・コード・銘柄名・数量・約定価格を入れ、「売買を確認」を押す
3. 「判定：有効」と出たら「GitHubで記入する」を押す
4. GitHub の画面で「Commit changes...」→「Commit changes」を押す
5. 1〜2 分後にページを再読み込みし、売買実績に載ったことを確かめる

現在値は「現在値」欄から同じ手順で記入する。取消は売買実績の「取消」から GitHub の削除画面を開き、確定する。

## Claude の記入方法

このリポジトリに `entries/` のファイルを追加して push する。

## 自動表示

- 合計資産（現金＋保有株式の時価）が 200,000 円を下回ると「警告」
- 合計資産が 0 円になると「中止」。以後のその参加者の売買は「中止後」として計算に入らない
- 信用取引なし（現金を超える買いは不可）、手数料なし
